# NVIDIA Video Classification

An industry-sponsored deep learning project developed in collaboration with NVIDIA, designed to classify video content into four categories with ~93–95% accuracy. This project was trained on an **NVIDIA A100 GPU (MIG partition)** and demonstrates a production-ready two-stage spatial-temporal pipeline built entirely from scratch.

## What this project does

The system classifies videos into four content categories:

| Category | Description |
|----------|-------------|
| **Animation** | Animated films, cartoons, CGI content |
| **Gaming** | Video game footage, gameplay recordings |
| **Natural Content** | Real-world footage: nature, sports, people |
| **Flat Content** | Screen recordings, slideshows, static visuals |

Unlike image classifiers, this system models both **spatial appearance** (per-frame features) and **temporal dynamics** (motion patterns across the video sequence).

## System architecture at a glance

```
Video Input
    │
    ▼
┌─────────────────────────────────────────┐
│  STAGE 1: Spatial Feature Extraction    │
│  CNN Backbone (ResNet-101 / EfficientNet│
│  Feature dim: 1280  |  Multi-scale      │
└─────────────────────┬───────────────────┘
                      │  Frame features [T × 1280]
                      ▼
┌─────────────────────────────────────────┐
│  STAGE 2: Temporal Modeling             │
│  Input Projection + LayerNorm           │
│  4-layer Bidirectional LSTM (768-dim)   │
│  12-head Multi-Head Self-Attention      │
│  Attention Pooling                      │
│  3-layer MLP Classifier                 │
└─────────────────────┬───────────────────┘
                      │
                      ▼
         Class Prediction (4 classes)
```
