This guide walks you through setting up the NVIDIA Video Classification system locally, installing dependencies, and running your first inference — either through the Flask web app or directly from the command line.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Python 3.8+**
- **pip** (Python package manager)
- **Git**
- **CUDA 11.8+** and **cuDNN** — required for GPU-accelerated inference (CPU fallback is available)
- **NVIDIA GPU** with at least 4 GB VRAM recommended (the system was trained on an NVIDIA A100 MIG partition with 9.8 GB VRAM)

<Note>
  The system automatically falls back to CPU if CUDA is not available. GPU inference is significantly faster, especially when loading all four ensemble models.
</Note>

## Setup

<Steps>
  <Step title="Clone the repository">
    Clone the project repository to your local machine:

    ```bash
    git clone <your-repo-url> nvidia-video-classification
    cd nvidia-video-classification
    ```
  </Step>

  <Step title="Create a virtual environment (recommended)">
    Create and activate a Python virtual environment to keep dependencies isolated:

    <CodeGroup>

    ```bash Linux / macOS
    python -m venv venv
    source venv/bin/activate
    ```

    ```bash Windows
    python -m venv venv
    venv\Scripts\activate
    ```

    </CodeGroup>
  </Step>

  <Step title="Install dependencies">
    Install all required packages:

    ```bash
    pip install -r requirements.txt
    ```

    The key dependencies are:

    | Package | Purpose |
    |---|---|
    | `torch`, `torchvision` | Deep learning framework and pretrained CNN backbones |
    | `flask` | Web server for the inference UI |
    | `opencv-python` | Video frame extraction and preprocessing |
    | `h5py` | Reading pre-extracted features stored in HDF5 format |
    | `numpy`, `pandas` | Numerical computation and data handling |
    | `scikit-learn` | Metrics (F1, precision, recall) |
    | `tqdm` | Progress bars during batch inference |
    | `matplotlib`, `seaborn` | Training plots and confusion matrices |
    | `psutil` | System resource monitoring |
    | `requests` | HTTP downloads for external video URLs |
    | `yt-dlp` | *(Optional)* Downloading videos from YouTube and other platforms |

    <Tip>
      Install `yt-dlp` separately if you plan to classify videos from external URLs: `pip install yt-dlp`
    </Tip>
  </Step>

  <Step title="Verify model checkpoints and feature files">
    Before running the app, confirm that the following files are present inside the `Flask Local New/` directory:

    ```
    Flask Local New/
    ├── app.py
    ├── test_already_extracted.py
    ├── model_train_new.py
    ├── index.html
    ├── models_enhanced/
    │   ├── best_ensemble_model_1.pt
    │   ├── best_ensemble_model_2.pt
    │   ├── best_ensemble_model_3.pt
    │   └── best_ensemble_model_4.pt
    ├── features_enhanced/
    │   └── test_features_multiscale.h5
    └── data/
        └── processed/
            └── test/
                ├── Animation/
                ├── Flat_Content/
                ├── Gaming/
                └── Natural_Content/
    ```

    <Warning>
      The app will not start if `test_already_extracted.py` is missing from the same directory as `app.py`. All four model checkpoints must be present in `models_enhanced/` for full ensemble inference.
    </Warning>
  </Step>
</Steps>

## Running the Flask web app

<Steps>
  <Step title="Start the server">
    Navigate to the `Flask Local New/` directory and launch the app:

    ```bash
    cd "Flask Local New"
    python app.py
    ```

    On startup, the app prints the resolved paths for all required files and directories:

    ```
    Index HTML path: /path/to/Flask Local New/index.html
    User script path: /path/to/Flask Local New/test_already_extracted.py
    Features dir: /path/to/Flask Local New/features_enhanced
    Models dir: /path/to/Flask Local New/models_enhanced
    Processed test dir: /path/to/Flask Local New/data/processed/test
    ```
  </Step>

  <Step title="Open the UI">
    Open your browser and go to:

    ```
    http://localhost:5000
    ```

    The web interface lets you:

    - Browse available test videos grouped by category
    - Select a video from the dataset
    - Enable or disable Test-Time Augmentation (TTA)
    - Run ensemble inference and view results
  </Step>
</Steps>

<Note>
  The server binds to `0.0.0.0:5000`, so it is accessible from other devices on the same network. In production, place it behind a reverse proxy and restrict access appropriately.
</Note>

## Running single-video inference from the command line

You can also run inference interactively without the web server using `test_already_extracted.py`:

```bash
cd "Flask Local New"
python test_already_extracted.py
```

The script starts in **interactive mode** and prompts you to select a video. You can provide:

- A **video number** from the displayed list (e.g., `42`)
- A **filename** from the dataset (e.g., `my_video.mp4`)
- A **local file path** to a video outside the dataset
- A **URL** (YouTube or direct `.mp4` link) — requires `yt-dlp` for YouTube

### Example session

```
SINGLE VIDEO INFERENCE - INTERACTIVE MODE
Using pre-extracted features from features_enhanced folder or external video URL/local file

Animation (12 videos):
     1. video_001.mp4
     2. video_002.mp4
   ...
Gaming (18 videos):
    13. video_g001.mp4
   ...

Enter video number or filename (or 'test' to run accuracy test, or paste a URL/local path): 1
```

After selecting a video, the classifier loads all four ensemble models and runs inference.

### Batch accuracy test

Enter `test` at the prompt to run a batch accuracy evaluation on a random sample of videos from the test set. You will be asked how many videos to test and whether to enable TTA.

### Classes and confidence

The model classifies videos into four categories:

| Class | Description |
|---|---|
| `Animation` | Animated video content |
| `Flat_Content` | Screen recordings, slides, or UI-heavy content |
| `Gaming` | Video game footage |
| `Natural_Content` | Real-world footage (nature, people, events) |

**Confidence** is the softmax probability of the predicted class, averaged across all four ensemble models. Values above 90% indicate high certainty. Enabling TTA can raise accuracy by 1–2% on borderline cases.

<Tip>
  Enable **Test-Time Augmentation (TTA)** for more reliable predictions on ambiguous videos. TTA runs inference four times with different temporal augmentations (original, reversed, speed-up, slow-down) and averages the results.
</Tip>
