The temporal model is implemented as `SuperEnhancedTemporalModel` in `model_train_new.py`. It receives a sequence of per-frame CNN features and outputs class logits. The design combines four components: an input projection, a bidirectional LSTM stack, multi-head self-attention, and an MLP classifier.

|---|---|

| `dropout` | 0.4 |
| `bidirectional` | `true` |

## Architecture

```python
class SuperEnhancedTemporalModel(nn.Module):
    def __init__(self, feature_dim=2048, hidden_dim=768, num_classes=4,
                 num_lstm_layers=4, num_attention_heads=12, dropout=0.4,
                 bidirectional=True):
        super().__init__()
        ...
```

### Input projection

The first sub-module standardizes the incoming features before the recurrent layers:

```python
self.input_projection = nn.Sequential(
    nn.Linear(feature_dim, hidden_dim),
    nn.LayerNorm(hidden_dim),
    nn.ReLU(),
    nn.Dropout(dropout * 0.5)   # 0.2 in production
)
```

`Linear(1280 → 768)` compresses the CNN feature dimension. LayerNorm and ReLU stabilize the distribution before it enters the LSTM. Dropout is halved here (0.2) to apply lighter regularization at the input.

### Bidirectional LSTM

```python
self.lstm = nn.LSTM(
    input_size=hidden_dim,      # 768
    hidden_size=hidden_dim,     # 768
    num_layers=num_lstm_layers, # 4
    batch_first=True,
    dropout=dropout if num_lstm_layers > 1 else 0,  # 0.4
    bidirectional=bidirectional  # True
)

lstm_output_dim = hidden_dim * 2  # 1536
```

Four stacked BiLSTM layers capture both short-range and long-range temporal dependencies. The bidirectional design ensures that each timestep's hidden state is informed by both past and future frames. The output dimension doubles to 1536 (forward 768 + backward 768).

Sequences are packed before the LSTM to prevent padding tokens from influencing hidden states:

```python
if lengths is not None:
    x = nn.utils.rnn.pack_padded_sequence(
        x, lengths.cpu(), batch_first=True, enforce_sorted=False
    )

lstm_out, _ = self.lstm(x)

if lengths is not None:
    lstm_out, _ = nn.utils.rnn.pad_packed_sequence(
        lstm_out, batch_first=True
    )
```

### Multi-head self-attention

```python
self.attention = nn.MultiheadAttention(
    embed_dim=lstm_output_dim,      # 1536
    num_heads=num_attention_heads,  # 12
    dropout=dropout,                # 0.4
    batch_first=True
)

self.attention_norm = nn.LayerNorm(lstm_output_dim)
self.attention_dropout = nn.Dropout(dropout)
```

Applied after the LSTM with a residual connection and post-norm:

```python
# Self-attention with residual
attended, _ = self.attention(lstm_out, lstm_out, lstm_out)
attended = self.attention_dropout(attended)
attended = self.attention_norm(lstm_out + attended)
```

The 12 attention heads allow the model to simultaneously attend to different aspects of temporal structure — for example, one head may focus on scene transitions while another tracks motion rhythm.

### Attention pooling

Rather than simply taking the last hidden state or averaging all timesteps, the model learns a per-frame importance score:

```python
self.attention_pooling = nn.Sequential(
    nn.Linear(lstm_output_dim, lstm_output_dim // 2),  # 1536 → 768
    nn.LayerNorm(lstm_output_dim // 2),
    nn.Tanh(),
    nn.Dropout(dropout * 0.5),
    nn.Linear(lstm_output_dim // 2, 1)                 # 768 → 1
)
```

The scalar scores are normalized and used as a weighted sum:

```python
attention_weights = self.attention_pooling(attended)   # [B, T, 1]
attention_weights = F.softmax(attention_weights, dim=1)
pooled = (attended * attention_weights).sum(dim=1)     # [B, 1536]
```

<Tip>
  Attention pooling is more expressive than mean or max pooling because the model can learn to focus on the most discriminative segments of each video — for instance, a game's HUD elements or an animation's characteristic visual rhythm.
</Tip>

### Classifier head

A three-layer MLP with normalization and dropout at every layer:

```python
self.classifier = nn.Sequential(
    nn.Linear(lstm_output_dim, 768),  # 1536 → 768
    nn.LayerNorm(768),
    nn.ReLU(),
    nn.Dropout(dropout),              # 0.4

    nn.Linear(768, 512),
    nn.LayerNorm(512),
    nn.ReLU(),
    nn.Dropout(dropout),              # 0.4

    nn.Linear(512, 256),
    nn.LayerNorm(256),
    nn.ReLU(),
    nn.Dropout(dropout * 0.5),        # 0.2

    nn.Linear(256, num_classes)       # → 4
)
```

The progressive width reduction (1536 → 768 → 512 → 256 → 4) applies increasingly aggressive compression before the final logits. LayerNorm at each layer reduces internal covariate shift without the batch-size dependency of BatchNorm.

## Full forward pass

```python
def forward(self, x, lengths=None):
    # [B, T, feature_dim] → [B, T, hidden_dim]
    x = self.input_projection(x)

    # Pack for LSTM efficiency
    if lengths is not None:
        x = nn.utils.rnn.pack_padded_sequence(
            x, lengths.cpu(), batch_first=True, enforce_sorted=False
        )

    # [B, T, hidden_dim] → [B, T, lstm_output_dim]
    lstm_out, _ = self.lstm(x)

    if lengths is not None:
        lstm_out, _ = nn.utils.rnn.pad_packed_sequence(
            lstm_out, batch_first=True
        )

    # Self-attention with residual connection
    attended, _ = self.attention(lstm_out, lstm_out, lstm_out)
    attended = self.attention_dropout(attended)
    attended = self.attention_norm(lstm_out + attended)

    # Attention pooling: [B, T, lstm_output_dim] → [B, lstm_output_dim]
    attention_weights = self.attention_pooling(attended)
    attention_weights = F.softmax(attention_weights, dim=1)
    pooled = (attended * attention_weights).sum(dim=1)

    # MLP: [B, lstm_output_dim] → [B, num_classes]
    output = self.classifier(pooled)

    return output
```

## Weight initialization

```python
def _initialize_weights(self):
    for m in self.modules():
        if isinstance(m, nn.Linear):
            nn.init.xavier_uniform_(m.weight)
            if m.bias is not None:
                nn.init.constant_(m.bias, 0)
        elif isinstance(m, nn.LayerNorm):
            nn.init.constant_(m.weight, 1)
            nn.init.constant_(m.bias, 0)
```

Xavier uniform initialization keeps gradient magnitudes stable at the start of training. LayerNorm weights are initialized to 1 (identity scale) and biases to 0, so normalization is a no-op before the first gradient update.

## Loss function

Training uses `FocalLoss` with label smoothing:

```python
class FocalLoss(nn.Module):
    def __init__(self, alpha=None, gamma=2.0, smoothing=0.1):
        super().__init__()
        self.alpha = alpha      # per-class weights tensor
        self.gamma = gamma      # focusing parameter
        self.smoothing = smoothing

    def forward(self, inputs, targets):
        num_classes = inputs.shape[1]

        # Label smoothing: replace hard 0/1 targets
        confidence = 1.0 - self.smoothing   # 0.9
        smooth_targets = torch.zeros_like(inputs)
        smooth_targets.fill_(self.smoothing / (num_classes - 1))  # 0.1/3 ≈ 0.033
        smooth_targets.scatter_(1, targets.unsqueeze(1), confidence)

        # Cross-entropy over smoothed targets
        log_probs = F.log_softmax(inputs, dim=1)
        ce_loss = -(smooth_targets * log_probs).sum(dim=1)

        # Focal weighting: down-weight easy examples
        pt = torch.exp(-ce_loss)
        focal_loss = (1 - pt) ** self.gamma * ce_loss  # gamma=2.0

        # Per-class alpha weighting
        if self.alpha is not None:
            at = self.alpha.gather(0, targets)
            focal_loss = at * focal_loss

        return focal_loss.mean()
```

<CardGroup cols={2}>
  <Card title="Label smoothing (0.1)" icon="sliders">
    Prevents overconfident predictions by replacing the hard target probability of 1.0 with 0.9, distributing the remaining 0.1 across other classes. Reduces overfitting and improves calibration.
  </Card>
  <Card title="Focal loss (gamma=2.0)" icon="bullseye">
    Multiplies the loss of each sample by `(1 - p_t)^2`, where `p_t` is the model's confidence in the correct class. Easy examples (high `p_t`) contribute little; hard examples dominate the gradient.
  </Card>
</CardGroup>

## Regularization summary

The model applies several independent regularization mechanisms that together reduce overfitting on the ~2,800-video training set:

<AccordionGroup>
  <Accordion title="Dropout (0.4)">
    Applied after each LSTM layer (inter-layer), within the attention module, and at every linear layer in the classifier head. The input projection and attention pooling use a lighter 0.2 rate.
  </Accordion>
  <Accordion title="Label smoothing (0.1)">
    Built into `FocalLoss`. Reduces the model's tendency to assign near-zero probability to non-target classes.
  </Accordion>
  <Accordion title="Weight decay (5e-4)">
    L2 penalty on all parameters via AdamW's decoupled weight decay. This penalizes large weights independently of the adaptive learning rate.
  </Accordion>
  <Accordion title="Gradient clipping (max norm 1.0)">
    Applied before each optimizer step. Prevents exploding gradients in the deep LSTM stack.
  </Accordion>
  <Accordion title="Temporal augmentation">
    During training, sequences are randomly subsampled (70–100% of frames), circularly shifted by ±3 frames, or perturbed with Gaussian noise (σ=0.01). Applied with probabilities 0.5, 0.3, and 0.2 respectively.
  </Accordion>
  <Accordion title="WeightedRandomSampler">
    Ensures each mini-batch contains a balanced class distribution. Combined with the alpha parameter in FocalLoss, this provides two independent sources of class-frequency correction.
  </Accordion>
</AccordionGroup>
